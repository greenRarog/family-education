# Сценарии обмена сообщениями

## Отклик создаёт диалог (conversation)

1. Пользователь A создаёт и публикует объявление (advertisement).
2. Пользователь B открывает объявление.
3. Пользователь B отправляет отклик (response) с первоначальным сообщением.
4. Отклик создаётся со статусом sent.
5. Создаётся диалог (conversation).
6. Создаётся первоначальное сообщение (message).
7. Пользователь A видит диалог.
8. Пользователь B видит диалог.

## Ожидающий отклик (pending response)

1. Статус отклика (response) — sent.
2. Пользователь B не может отправлять сообщения.
3. Пользователь B видит сообщение о том, что отклик необходимо принять.
4. Пользователь A может принять или отклонить отклик.

## Принятый отклик (accepted response)

1. Пользователь A принимает отклик.
2. Статус отклика (response) становится accepted.
3. Пользователь B может отправлять сообщения.
4. Пользователь A может отправлять сообщения.
5. Сообщения отображаются в диалоге.

## Отклонённый отклик (rejected response)

1. Пользователь A отклоняет отклик.
2. Статус отклика (response) становится rejected.
3. Пользователь B не может отправлять сообщения.

## Владелец может завершить диалог (terminate conversation)

1. Отклик находится в статусе accepted.
2. Пользователь A может отозвать/отклонить отклик.
3. Диалог (conversation) остаётся доступным.
4. Дальнейшая отправка сообщений отключена.

## Прочитанные/непрочитанные сообщения (read/unread)

1. Пользователь B отправляет сообщение.
2. Пользователь A видит диалог как непрочитанный.
3. Пользователь A открывает диалог.
4. Сообщения становятся прочитанными.
5. Диалог больше не отображается как непрочитанный.
