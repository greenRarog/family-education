# Сценарии обмена сообщениями

Актуально: 2 ноября 2026. Действующие ограничения — [роли и лимиты](../action-rules.md),
[модерация](../moderation-rules-c01.md), [удаление и хранение](../account-lifecycle.md).
Ниже обычный сценарий активных участников; блокировка и удаление имеют приоритет.

## Создание диалога

1. Владелец публикует объявление.
2. Другой пользователь разрешённой роли с подтверждённым email отправляет отклик.
3. Атомарно создаются отклик `sent`, диалог и первое обязательное сообщение.
4. История доступна только двум участникам; посторонний admin доступа не получает.

## Права по статусу отклика

| Статус | Владелец объявления | Автор отклика |
| --- | --- | --- |
| `sent` | Пишет, принимает или отклоняет отклик | Читает, ждёт принятия |
| `accepted` | Пишет, может завершить отклик | Пишет |
| `rejected` | Только читает | Только читает |

Завершение отклика не закрывает само объявление. Истечение объявления не
завершает уже принятый диалог. Блокировка приостанавливает общение, удаление
переводит историю в чтение со сроком по ссылкам выше.

## Обновление и прочтение

Список и история загружаются порциями; polling получает новые сообщения.
Открытие видимого диалога отправляет read receipt до подтверждённого курсора;
позднейшие сообщения не считаются прочитанными этим запросом. Скрытая вкладка
приостанавливает polling, возвращение обновляет состояние. Временный сбой
допускает повтор, отказ 401/403/404 очищает историю и прекращает polling.
У удалённого участника новые read receipts и непрочитанные не создаются.
