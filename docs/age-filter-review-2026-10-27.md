# A08 — возрастной фильтр и подпись возраста

Дата: 27 октября 2026 года. **A08 выполнен, PASS:** 5 целевых PHPUnit-тестов, 68 утверждений; 12 проверок выражения UI-подписи. Полная страница в браузере не запускалась — это остаётся A16.

## Проверенное поведение

Исходный возрастной тест прошёл (1 тест, 24 утверждения). В [PublicAdvertisementTest](../tests/Feature/PublicAdvertisementTest.php) расширены проверки:

- Опубликованная услуга `teacher_to_service` с обеими границами `null` включается при возрасте 0, 6, 7, 10, 11 и 100.
- Диапазон 7–10 включителен для всех трёх типов объявлений: 7 и 10 подходят, 0/6/11/100 — нет.
- Услуги без возраста в draft/closed не попадают в выдачу.
- Отсутствующий параметр age и пустое `age=` не ограничивают возраст; возвращаются все четыре опубликованные записи тестового набора.
- Исключение для `null/null` действует только для услуг. Семейные объявления без обеих границ и услуги с одной отсутствующей границей не считаются подходящими при age=8. Такие записи созданы фабрикой для проверки поведения фильтра; это не утверждение, что API создания допускает их.
- Услуги без возрастных ограничений не обходят фильтры типа, города, формата, языка и предмета.
- Возраст -1, 101, 7.5 и abc возвращает 422 с ошибкой поля age.

Дополнительно прошёл существующий `AdvertisementTest::test_public_feed_can_filter_advertisements_by_age`. Контроллер уже правильно группирует условие диапазона и исключение для услуг внутри общего WHERE. Исправлять код приложения не потребовалось.

## Подпись в интерфейсе

В [AdvertisementShow](../../frontend/src/pages/AdvertisementShow.jsx) условие `from == null && to == null` выбирает «Любой возраст»; числовой ноль не считается отсутствующим значением. Проверено фактическое выражение, извлечённое из компонента, с проектной функцией `tr` и React `renderToStaticMarkup` для текстового фрагмента:

| Границы | RU | EN | ES |
| --- | --- | --- | --- |
| null / null | Любой возраст | Any age | Cualquier edad |
| 0 / 0 | 0–0 лет | 0–0 years old | 0–0 años |
| 0 / 100 | 0–100 лет | 0–100 years old | 0–100 años |
| 7 / 10 | 7–10 лет | 7–10 years old | 7–10 años |

Все 12 случаев PASS на Node 24.15.0. Первая временная проверка ожидала английское `years`, тогда как словарь использует `years old`; исправлено ожидание smoke-проверки, приложение не менялось. В компоненте фильтров пустая опция также подписана «Любой возраст»; её код просмотрен. Выбор возраста в UI предлагает 0–18, тогда как API допускает 0–100; эта существующая разница не менялась.

Это исполнение выражения и рендеринг отдельного текстового фрагмента, не монтаж всей страницы, загрузка API или проверка видимости в браузере. Chromium Playwright отсутствует; установка и полный browser suite остаются A16. Существующий e2e-сценарий подписи в этой задаче не выполнялся. Frontend-файлы не изменялись.
