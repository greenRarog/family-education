## Проверка загрузки истории

Набор пагинации содержит 120 сообщений: по два в 20 диалогах и 80 в диалоге на второй странице. После создания фикстур слушатель `eloquent.retrieved: App\Models\Message` фиксирует модели Message, действительно извлечённые при HTTP-запросе.

- Первая страница загрузила ровно 20 Message с id последних сообщений её диалогов.
- Вторая страница загрузила ровно одну Message с последним id, хотя история этого диалога содержит 80 сообщений.
- Поле messages отсутствует во всех 21 строках JSON.

Это подтверждает отсутствие загрузки полных историй в Eloquent, а не только их исключение из JSON. SQL-агрегаты EXISTS/COUNT для unread и MAX для lastMessage остаются частью запросов. Производительность SQL на большой PostgreSQL-базе, планы запросов и постоянное число запросов этим тестом не измерялись.
