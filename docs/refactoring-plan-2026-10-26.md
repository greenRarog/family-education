# План завершения разработки и первого запуска

Актуально: 5 ноября 2026. **Локальный этап выполнен; следующий — VPS.**
Сервис ещё не эксплуатировался, пользовательской БД для переноса нет: только
сидеры и тестовые данные. VPS пока недоступен.

Это единственный список статусов и оставшихся задач. README содержат команды,
предметные документы — действующие правила. Старые A–F сохранены лишь как
обозначения прежних областей, а не последовательность будущей работы.

## Принятые границы

- Бекапы настраиваются **только на VPS**: расписание, внешние копии, ротация,
  восстановление и оповещения. В локали рабочие бекапы не настраиваем.
- Первый запуск: новая БД, миграции, справочники и первый admin. Демоданные
  не переносить; найденные на VPS тома сначала осмотреть.
- MAX работает по сценарию Telegram: ссылка → код бота → подтверждение в той же
  сессии → отдельное согласие на уведомления → отключение на сайте.
  У владельца есть ИП, но профиля партнёра MAX и бота пока нет: создать в V05.
- **SEO целиком отложено в отдельную задачу и не блокирует эти этапы.**
  Когда вернёмся: сначала предложить варианты широты, после выбора определить
  объём. Сейчас ничего для индексации/SSR не меняем. Дипломы также отложены.
- Удаление аккаунта выключено до приёмки хранения/восстановления на VPS.
  Наличие кода и локальных тестов не означает допуска к включению.

## Последние проверки и их границы

5 ноября, одноразовые локальные стенды и синтетические данные:

- Backend: PostgreSQL **891 PASS / 11 971 assertions**, включая отдельную
  PostgreSQL-БД реестра; SQLite **823 PASS + 68 skip / 9 831 assertions**.
  Пропуски SQLite — PostgreSQL-специфичные проверки. Отдельно **10 PASS** для
  MAX через Redis queue и очистки Redis. Pint/Larastan — PASS.
- Frontend: lint, **40 unit**, build — PASS. **242 browser-сценария**:
  общий прогон 237 PASS и 5 устаревших ожиданий настроек; исправленный набор
  настроек 6/6 PASS. MAX/Telegram проверены в общем прогоне. Это общий прогон
  плюс целевой повтор, не один чистый прогон всех 242.
- Настоящий Laravel/PostgreSQL + браузер: **4 PASS** — удаление/хранение и
  MAX connect/code/opt-in/reload/unlink для обеих ролей. Внешний Bot API,
  Turnstile и реестр здесь тестовые; PostgreSQL-адаптер реестра проверен отдельно.
- Infrastructure: **38 unit PASS**; текущие backend/nginx/frontend images
  собраны, `bin/e2e start/check` проходит HTTP/session/CSRF/Fortify и тестовые
  Cloudflare tokens. Обычный local Compose с реальным VLESS не запускался.
- Осталось предупреждение сборки SPA о chunk >500 kB (около 146 kB gzip);
  сборка успешна. Оптимизация загрузки возможна отдельно, переписывание не требуется.

Результаты для продолжения сохранены выше. Подробные логи и машинная сводка
остались локально в `.local-stage-test`, в Git не входят и для новой машины
не требуются. Исторические release/backup/restore проверки также вне Git; новый прогон
рабочего backup/restore локально не выполнялся. Настоящие sealed release,
VPS/TLS, SMTP/Bot API, сроки хранения, мониторинг и восстановление сервиса
**не подтверждены**. Тестовый `deletion_acceptance` не создавался для рабочей цели.
